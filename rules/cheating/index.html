1. Cheating, Exploits & Alternate Accounts

1.1 Unfair Modifications

Using any client, mod, macro, or tool that gives an unfair advantage over other players is not allowed. This includes hacked clients, X-ray, automation tools, or similar advantages.

Using stolen or illegitimate Minecraft accounts is also forbidden.

Allowed examples include:

  • Performance improvement mods
  • Armor, potion, and status HUD mods
  • Minimap mods that do not reveal more information than the server map
  • Purely visual or aesthetic mods
  • Litematica without printer functionality

If unsure, ask staff before using a modification.

1.2 Assisting Rule Breaking

Helping, supporting, or knowingly benefiting from another player breaking server rules may result in punishment as if you committed the violation yourself.

1.3 Bugs, Exploits & Duplication

Abusing glitches, duplication methods, or technical flaws is not allowed. Any discovered issues should be reported to staff immediately.

1.4 Alternate Accounts

Only one account per player is allowed. Using multiple accounts, sharing accounts, or using alts to gain an advantage is not permitted.

Players on the same network are allowed, as long as each person controls only their own account.

1.5 Server Disruption

Deliberately causing lag, crashes, or disruption to EarthTowny services is strictly forbidden.
